## 📁 Структура проекта

- **Bot_IT_Support** — проект бота для ИТ-поддержки, использует MongoDB для хранения данных.  
- **Chat_Bots** — эксперименты с асинхронными чат-ботами.  
- **Computer_vision** — задания по компьютерному зрению.  
- **Coursework / Coursework2** — курсовые работы, включая проект по бинарной классификации аномалий и классификации текстов.  
- **Graph** — задачи, связанные с графовыми структурами и алгоритмами.  
- **Mobile_development** — лабораторные работы по мобильной разработке.  
- **NLP** — эксперименты с моделями обработки естественного языка.  
- **RecSys** — эксперименты с рекомендательными системами.  
- **Semantic_technologies** — проекты, связанные с семантическим анализом данных.  
- **Veb_exs** — практические упражнения по веб-разработке.  

## 🚀 Технологии
- Python (NumPy, pandas, PyTorch, scikit-learn)
- MongoDB
- Git / GitHub
- VS Code, Google Colab
